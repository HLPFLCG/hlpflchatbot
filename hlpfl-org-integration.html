🔧 Chatbot Integration Guide

The HLPFL Chatbot is now integrated into this website! It provides instant support for artists, information about services, and answers to common questions.

Status: Live and Running

To add the chatbot to your website, add this code:

1. Add to <head> section:

<link rel="stylesheet" href="https://hlpfl.io/chat-widget.css">

2. Add before closing </body> tag:

<div id="hlpfl-chat-widget"></div>
<script src="https://hlpfl.io/chat-widget.js"></script>
<script>
  HLPFLChat.init({
    apiUrl: 'https://hlpfl.io/api/chat',
    position: 'bottom-right',
    primaryColor: '#CD8B5C',
    companyName: 'HLPFL Records',
    showWelcomeMessage: true,
    welcomeMessage: 'Hi! 👋 Welcome to HLPFL Records. How can I help you today?'
  });
</script>

💬 Try the Chatbot

Click the chat button in the bottom-right corner to try the HLPFL Chatbot!

Test these messages:

  • "hello" - Get a greeting
  • "What services do you offer?" - Learn about our services
  • "How do I submit my music?" - Get submission instructions
  • "contact" - Get contact information
  • "Tell me about your company" - Learn about HLPFL
  • "Who is PRIV?" - Learn about our featured artist
